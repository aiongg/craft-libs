# craft-draw

Vector and shape tools for Craft apps. With the `ui` feature, `craft_draw::ui` has the gradient tools (`GradientEditor`, `GradientPalette`, `GradientSwatch`, `GradientRamp`, the stop rules in `gradient::stops`, and the on-canvas `GradientOverlay` with its `gradient_line` geometry), with their stories and words (`craft_draw::ui::stories()`, `craft_draw::ui::WORDS`).

The gradient editor uses the colour picker and wells of `craft-color`.
