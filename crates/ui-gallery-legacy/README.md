# craft-ui-gallery

The component gallery for the Craft design system. Run it with `cargo run --release -p craft-ui-gallery-legacy`, or for the web `trunk serve --release true index.html` in this folder.

Contents:

- an overview with one tile per component of a layer
- a tab per component with all its stories
- a variants view: the selected story once per theme, mode, contrast or size
- the appearance bar and its More popover
